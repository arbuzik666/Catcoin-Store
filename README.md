# Catcoin-Store
🐱 Catcoin Store

Веб-приложение интернет-магазина на основе микрофреймворка Flask (Python).

**Выпускная квалификационная работа** по специальности 09.02.07 «Информационные системы и программирование».

---

О проекте

Catcoin — это полнофункциональный интернет-магазин с уникальным дизайном в пастельно-рыжих тонах и кошачьей тематикой. Приложение разработано с использованием модульной архитектуры на Flask Blueprints и включает клиентскую часть для покупателей и административную панель для управления магазином.

---

Основные функции

Для покупателя
- 🛍️ Просмотр каталога товаров с фильтрацией по категориям
- 🔍 Поиск товаров по названию
- 🛒 Корзина покупателя (добавление, изменение, удаление)
- 📦 Оформление заказа
- 📋 История заказов
- ⭐ Система отзывов и рейтинга (только для купленных товаров)
- ❤️ Избранное

### Для администратора
- 📊 Дашборд со статистикой
- 📦 Управление товарами (добавление, редактирование, удаление)
- 🏷️ Управление категориями
- 📋 Обработка заказов (просмотр, смена статуса)
- 👤 Просмотр пользователей
- 🗑️ Модерация отзывов

## Структура проекта

Приложение построено на модульной архитектуре с использованием Flask Blueprints:

- `main` — каталог товаров, поиск, фильтрация
- `auth` — регистрация, вход, выход
- `cart` — корзина покупателя
- `order` — оформление заказа, история
- `favorites` — избранное
- `admin` — административная панель

### Установка и запуск

1. Откройте проект в Visual Studio Code

Запустите VS Code и откройте папку с проектом:
**File → Open Folder → выберите папку `App`**

2. Откройте терминал

В VS Code нажмите **Terminal → New Terminal** или сочетание клавиш **Ctrl + `**

3. Установите зависимости
pip install -r requirements.txt

4. Запуск
python app.py
